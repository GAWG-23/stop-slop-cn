# 删掉的词和套话

## 开篇废话

AI 总要在说正事之前先来一段垫场。直接删。

- "在当今……的时代/背景下"
- "随着……的不断发展/深入"
- "众所周知"
- "不可否认的是"
- "值得一提的是"
- "需要指出的是"
- "应当看到"
- "我们不难发现"
- "从整体上来看"
- "可以预见的是"

凡是 "在……下/中/背景下" 开头、还没进入正题的句子，整句删掉。

## 强调废话

这些词不添加任何信息，删掉不影响意思。

- "毫无疑问"
- "毋庸置疑"
- "显而易见"
- "不言而喻"
- "不可忽视的是"
- "必须强调的是"
- "尤其值得关注的是"
- "特别需要说明的是"

| 黑话 | 替换 |
|---|---|
| 赋能 | 帮助 / 支撑 / 让……能做 |
| 抓手 | 关键措施 / 切入点 |
| 闭环 | 完整流程 / 从头到尾 |
| 底层逻辑 | 基本思路 / 核心原理 |
| 颗粒度 | 细节 / 精细程度 |
| 对齐 | 同步 / 确认 / 达成一致 |
| 拉通 | 协调 / 沟通 / 串联 |
| 倒逼 | 反过来推动 / 促使 |
| 打法 | 方法 / 策略 |
| 深耕 | 专注 / 深入 |
| 落地 | 执行 / 实施 |
| 护城河 | 壁垒 / 优势 |
| 降维打击 | 碾压式竞争 |
| 天花板 | 上限 / 瓶颈 |
| 盘活 | 激活 / 重新利用 |
| 引爆 | 引发 / 带动 |

## 空泛修饰词

这些修饰词后面如果没有具体内容，就是空的，直接删。

- "全方位" —— 到底哪几方面？
- "多维度" —— 哪几个维度？
- "系统性" —— 系统在哪儿？
- "深度" —— 多深？
- "全面" —— 到底覆盖了哪些？
- "充分" —— 怎么算充分？
- "积极" —— 每条都是积极的，等于没说
- "大力" —— 多大力？
- "高度" —— 多高？

改法：要么用具体事实替换，要么删掉。

## 万能动词壳

AI 不说动词，非要前面套个壳。

| 套壳 | 直接说 |
|---|---|
| 进行分析 | 分析 |
| 开展调研 | 调研 |
| 实施部署 | 部署 |
| 进行优化 | 优化 |
| 推动落地 | 推广 / 执行 |
| 促进协同 | — 删掉，直接说怎么做 |
| 强化意识 | — 删掉，换具体措施 |
| 实现……的提升 | 提升 |
| 完成……的建设 | 建成 |
| 取得……的突破 | 突破 |
| 带来……的改善 | 改善 |

## 退路词

AI 怕说错话，每句话都要留退路。删掉。

| 退路表达 | 改法 |
|---|---|
| 在一定程度上 / 某种程度 | 删掉 |
| 总体来看 / 整体而言 | 删掉 |
| 基本可以认为 | 删掉，直接说结论 |
| 不排除……的可能 | 可能 / 也许会 |
| 存在一定的……的空间 | 可以 / 还能 |
| 在一定条件下 | 满足X条件后 |

## 万能过渡词

| 删掉 | 原因 |
|---|---|
| 首先 / 其次 / 再次 / 最后 | 用内容逻辑自然衔接 |
| 此外 / 另外 / 除此之外 | 同上 |
| 综上所述 / 总而言之 | 删掉，直接说结论 |
| 值得注意的是 | 直接说 |
| 与此同时 | "同时" 或删掉 |

## 模糊泛化词

说了一个判断，但没说是谁、是什么、怎么量化，等于没说。

| 表达 | 问题 |
|---|---|
| 具有重要意义 | 什么意义？对谁有意义？ |
| 影响深远 | 影响了什么？怎么量化？ |
| 前景广阔 | 多广阔？依据是什么？ |
| 值得关注 | 为什么值得？关注了然后呢？ |
| 效果显著 | 显著到什么程度？数据呢？ |

改法：用具体事实或数据替换。

## 括号举例（"如XXX、XXX"）

AI 写完一个概括性的词，总要在后面加括号补几个例子，生怕读者不懂。人写东西不需要每个概念都配示例。

| 模式 | 问题 |
|---|---|
| "多种技术（如深度学习、自然语言处理、计算机视觉）" | 括号里的例子读者大概率知道，不需要解释 |
| "各个领域（如医疗、教育、金融）" | 列了三个行业，但没说具体怎么用 |
| "关键指标（如用户留存率、日活、转化率）" | 如果后面要展开说，括号多余；如果不说，列了也没用 |
| "多种方式（如线上推广、线下活动、社交媒体）" | 同上 |

**改法**：

- 如果括号里的内容是常识 → 删掉括号部分
- 如果括号里的内容确实需要 → 去掉括号，直接写进正文，变成句子的一部分
- 如果括号里列了一堆但后面不会展开 → 删掉，只保留概括词

**改写前：**
> 该平台支持多种数据源接入（如 MySQL、PostgreSQL、MongoDB），并提供丰富的可视化图表（如柱状图、折线图、饼图）。

**改写后：**
> 该平台支持 MySQL、PostgreSQL、MongoDB 等数据源接入，可视化方面提供柱状图、折线图和饼图。

或者更简洁：

> 该平台支持主流数据库接入，提供柱状图、折线图等常用图表。
