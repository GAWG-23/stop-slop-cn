# 要避免的结构

## 二元对立（"不是……而是……"）

制造虚假的戏剧感。直接说结论。

| 模式 | 问题 |
|---|---|
| "不是A，而是B" | 虚假反转，像是在揭穿什么 |
| "与其说A，不如说B" | 绕弯子 |
| "问题不在于A，而在于B" | 加戏 |
| "A不是关键，B才是" | 刻意制造对比 |
| "表面看是A，实际上是B" | 故作深刻 |

**改法**：直接说B。读者不需要先被告知"不是A"。

## 负向铺垫（先说不是什么，再说是什么）

列出几条"不是什么"，最后才说"其实是什么"。像在吊胃口。

| 模式 | 问题 |
|---|---|
| "不是X……也不是Y……而是Z" | 戏剧化铺垫 |
| "这不只是A，更是B" | 假递进 |

**改法**：直接说Z。

## 万能开头句式

| 模式 | 问题 |
|---|---|
| "从……角度来看" | 模板化开头 |
| "在……层面/维度上" | 同上 |
| "就……而言" | 同上 |
| "基于……的考虑" | 同上 |

**改法**：主语直接开头，动词直接跟上。

## 被动躲主语

AI 喜欢让事情"被发生"，不敢说是谁干的。

| 模式 | 改法 |
|---|---|
| "数据分析表明" | 谁分析了数据？→ "我们分析数据后发现" |
| "市场普遍认为" | 谁认为？→ "业内最普遍的看法是" |
| "可以预见" | 谁预见？→ "我们预计" |
| "建议采取" | 谁建议？→ "我们建议" |
| "被视为" | 谁在看待？→ "行业内普遍这样看" |
| "被广泛认可" | 谁认可？→ 说出认可的人或群体 |

## 总-分-总三段论

每段都按"观点标题→展开论述→归纳小结"的结构，读起来像在答题。

**改法**：
- 该分点就分点，不要每段都小结
- 部分段落可以直接是案例、数据或引用，不需要套模板
- 最后一段有总结就够了，不需要每段都总结

## 硬凑排比

三个四字短语并列，读起来整整齐齐但空洞无物。

| 模式 | 问题 |
|---|---|
| "全面性、系统性、前瞻性" | 三个空词叠一起还是空 |
| "更高效、更智能、更便捷" | 到底改了什么？ |
| "标准化、流程化、自动化" | 同上 |

**改法**：要么用一个精准的词，要么展开说具体做了什么。

## 信息埋在大段文字里

应该用列表展示的并列信息，被 AI 硬塞进了段落中。

**改法**：并列信息超过3条，直接上列表。列表配小标题，层次更清楚。

## 句子节奏问题

| 模式 | 改法 |
|---|---|
| 每句差不多长 | 短句下判断，长句讲道理，交替出现 |
| 超过50字的长句 | 拆成两句 |
| 段落第一句全是"XX是……" | 换一种开头方式 |
| 每段结尾都在总结 | 删掉，下一段直接接上 |

## 充当"上帝视角"

AI 站在高空点评，不敢站在读者身边说话。

| 模式 | 问题 |
|---|---|
| "人们往往" | 谁？你这个"往往"的数据从哪来？ |
| "大多数人" | 同上 |
| "不难发现" | 谁发现的？ |
| "众所周知" | 真的都知吗？ |

**改法**：用"你"直接对读者说话，或用"我们"表示团队视角。
