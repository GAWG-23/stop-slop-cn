# 去AI味 · 中文人味改写

把任何带「AI味」的中文文本，改写成读起来像是一个普通中国人在说话、在打字、在发朋友圈那种自然到骨子里的感觉。

## 这玩意儿干嘛用的？

你有没有觉得AI写出来的中文有一股说不出的怪味——句子太整齐、用词太讲究、逻辑太严密、就是不像人写的。

这个项目就是来解决这个问题的。它是一套完整的改写规则，告诉你怎么把AI味洗掉，换成真人说话的味道。

## 怎么用？

把 `SKILL.md` 装到你的 AI 工具里（Trae / Claude / ChatGPT 等支持 SKILL 的都可以），然后对着 AI 说：

> "帮我把这段话改得像人话一点"
> "这段太AI了，去去味儿"
> "润色得口语化一点，别那么机器"

AI 就会照着这套规则帮你改。

## 核心思路

偷懒版总结：

| 规则 | 一句话 |
|---|---|
| 打碎句子 | 长句拆短，关联词扔掉 |
| 别解释太多 | 默认读者懂，不懂拉倒 |
| 加人的存在感 | 用「我觉得」「你懂的」 |
| 真口语 | 「非常」→「贼」，「进行」→「搞」 |
| 拿生活打比方 | 「续航长」→「跟骆驼似的」 |
| 允许不完美 | 加点「呃」「怎么说呢」「反正就那样」 |
| 段落短 | 手机上看一坨字 = 直接划走 |

## 效果对比

**AI味：**
> 这款产品不仅在性能上表现出色，而且在设计上也独树一帜，可以称得上是同价位中最值得购买的选择。

**人味：**
> 这玩意儿用起来真挺快，长得也好看，同价位你找不到比它能打的。
