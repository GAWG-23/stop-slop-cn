# 写人话

> 把 AI 写的方案、文档、报告，改得像人写的。

AI 写东西很好用，但写出来一股机械味——动词不直接上、修饰词堆成山、每段都一个模子。`写人话` 是一套写法规则，把这些毛病洗掉。

核心思路来自英文领域很火的 [stop-slop](https://github.com/hvpandya/stop-slop)，针对中文职业写作场景做了完整适配——新增了中文互联网黑话清洗、万能动词壳剥除、退路词删除等中文独有的规则。

## 怎么用

把 `SKILL.md` 装到 Trae / Claude 等支持 SKILL 的工具里，一句话触发：

> "帮我去AI味"
> "改得像人写的"
> "太模板化了，重写"

## 文件结构

```
├── SKILL.md                    # 核心规则：8条 + 速查清单 + 评分系统
├── references/
│   ├── phrases.md              # 删掉的词和套话（开篇废话/黑话/泛化词/退路词）
│   ├── structures.md           # 要避免的结构（二元对立/排比/躲主语/节奏问题）
│   └── examples.md             # 6组改写前后对比（方案/技术文档/邮件/产品/需求/汇报）
├── README.md
└── LICENSE
```

## 8 条规则速览

| 规则 | 一句话 |
|---|---|
| 砍套话 | "在当今……的背景下" → 删 |
| 破模板 | 不做"不是A而是B" |
| 动词直接上 | "进行分析" → "分析" |
| 说具体的 | "效果显著" → "从 800ms 降到 200ms" |
| 主语别躲 | "建议" → "我们建议" |
| 句子有长短 | 短句判断，长句讲道理 |
| 相信读者 | "基本可行" → "可行" |
| 不写金句 | 像颁奖词的句子，重写 |

## 评分

每段文字改完打 1-10 分，五个维度：直接性 / 节奏 / 信任 / 真实感 / 信息密度。低于 35 分继续改。

## 效果

**AI味（50字）：**
> 在当今竞争激烈的市场环境下，本方案旨在通过系统性梳理用户旅程、深入挖掘痛点，全面提升用户体验水平。

**人味（25字）：**
> 用户对体验要求越来越高，但产品还停在"堆功能"的阶段。目标：满意度从 3.2 提到 4.0。

字数少了，信息量反而大了。
