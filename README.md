# 去AI味 · 中文人味改写

把 AI 生成的中文方案、文档、报告里的「机械味」洗掉——保留正常语法和专业感，但读起来像是一个有经验的从业者自己写的，而不是从模板里倒出来的。

## 解决什么问题？

AI 写方案很好用，但写出来的东西一眼就能认：

- 不说「分析」，非要说「进行分析」
- 修饰词不要钱似的往上堆：「全方位、多维度、系统性、深度」
- 「首先……其次……再次……最后」像在做PPT大纲
- 每句话都要留退路：「在某种程度上」「基本可以认为」
- 一段话读完忘了主语在哪

这个项目是一套改写规则，教你怎么把这些毛病去掉。

## 怎么用？

把 `SKILL.md` 装到 Trae / Claude / ChatGPT 等支持 SKILL 的工具里，然后说：

> "帮我把这段话改得像人写的"
> "这段太模板化了，去去AI味"
> "润色得更自然一点，别那么机械"

就会照着这套规则改。

## 8 条核心规则

| 规则 | 一句话 |
|---|---|
| 动词直接上 | 「进行分析」→「分析」 |
| 修饰词不凑数 | 「全方位多层次」→ 具体列出几方面 |
| 过渡靠逻辑 | 不用「首先其次」，用内容本身衔接 |
| 句子长短交替 | 短句下判断，长句讲道理 |
| 主语交代清楚 | 「建议」前面加上谁建议的 |
| 判断不含糊 | 「基本可行」→「可行」 |
| 信息用列表 | 并列内容不埋在大段文字里 |
| 开头说重点 | 不搞三段背景铺垫 |

## 效果对比

**AI味（方案开篇）：**
> 在当前竞争日益激烈的市场环境下，用户对产品的体验要求不断提升，传统的功能驱动型产品策略已经难以满足日益多元化的用户需求。为应对这一挑战，本方案旨在通过系统性地梳理用户旅程、深入挖掘用户痛点……

**人味改写：**
> 用户对体验的要求越来越高，但我们的产品还停留在「堆功能」的阶段。
>
> 这个方案做三件事：
> 1. 梳理用户的核心使用路径，找出卡点
> 2. 针对每个卡点给出优化方案
> 3. 定一个可衡量的体验指标，追踪效果
>
> 目标是把用户满意度从当前的 3.2 提到 4.0。
